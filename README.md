# Weather Application [![Netlify Status](https://api.netlify.com/api/v1/badges/dd61cac8-57d1-4f32-ac8a-a86e8f9361b4/deploy-status)](https://app.netlify.com/projects/weather-application-mii/deploys)
This is a simple weather update application. Get weather update by any city name.


## Live Demo
[Weather Application](https://weather-application-mii.netlify.app/)


## Run Development Version:
```bash
$ yarn install
$ yarn run dev
```


## Run Production Version:
```bash
$ yarn install
$ yarn run build
$ yarn run preview
```
